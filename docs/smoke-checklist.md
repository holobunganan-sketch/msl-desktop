# 维护验证清单

本清单用于每次候选构建的独立验收。历史执行结果不作为当前版本通过的证明。

## 测试边界

- [ ] 使用与正式数据分离的合成环境；优先放在仓库之外，仓库内只使用已忽略且经过路径校验的 `.test-runtime`。
- [ ] APPDATA、LOCALAPPDATA、TEMP、TMP 同时指向同一个隔离测试 profile 的独立子目录。
- [ ] 原生测试设置 `MSL_ISOLATED_TEST=1`；profile 路径含 `.test-runtime`，避免与正式单实例锁混淆。
- [ ] 使用本地 Mock Provider，不读取真实 Key、不调用真实模型、不打开正式数据库或真实工作目录。
- [ ] 所有截图只含合成记录；测试结果放在仓库之外或已忽略的隔离运行目录，不能提交或发布。
- [ ] 卸载、安装、提交和推送单独获得授权，不混入运行测试。

## 自动化检查

- [ ] `pnpm check` 和 `pnpm build` 通过。
- [ ] `node --test --test-concurrency=1 tests/*.test.mjs scripts/dashboard-ui.test.mjs` 通过。
- [ ] `cargo fmt --manifest-path src-tauri/Cargo.toml --check` 通过。
- [ ] `cargo test --manifest-path src-tauri/Cargo.toml -- --test-threads=1` 通过。
- [ ] 默认跳过的长时回环和数据库副本测试单独执行，并明确副本来源为合成或真实副本。
- [ ] 使用合成旧版本数据库验证迁移、重复打开、完整性和外键。
- [ ] `pnpm tauri build` 成功后记录实际二进制版本与摘要。
- [ ] `pnpm check:publish` 通过；另行审阅文档、示例及图片的隐私内容。文件名扫描不能证明全部内容安全。

## 原生界面与交互

CDP 脚本连接隔离的实际 WebView；设置 `MSL_TEST_PROFILE`、`MSL_CDP_PORT` 和 Playwright 模块路径 `MSL_NODE_MODULES`。生成 fixture 前先由隔离应用初始化数据库。

- [ ] 用 `ui-spacing-fixture.mjs` 建立合成布局数据。
- [ ] 用 `ui-spacing-cdp.mjs --expanded` 检查全部页面、窗口尺寸及字号。
- [ ] 用 `ui-detail-cdp.mjs` 检查表单、删除弹窗和专家详情。
- [ ] 用 `layout-regression.mjs --delete --catalog` 验证稳定控件、焦点、折叠、会话切换和阅读位置；另设外部 `MSL_TEST_ROOT`。
- [ ] 长标题、长错误、大字号、空列表及多页记录没有遮挡、叠放或无法到达的操作。
- [ ] 项目和专家删除要求完整名称及当前版本，取消不修改记录。
- [ ] 项目关联与独立事项的筛选正确，收件箱转换失败保留原记录。
- [ ] 分页展示能够访问最后一条记录，不改变数据及关联；筛选后页码有效。
- [ ] 新建、编辑、完成、等待跟进和日历安排可从对应页面操作。
- [ ] 截图完成独立视觉审阅。

## 工作连续性

- [ ] 从项目进入审阅、新建事项及来源详情时保留当前项目范围，可以返回来处。
- [ ] 专家交流草稿按专家分别保存；切页、切专家和保存中的继续输入不会互相覆盖。
- [ ] 从专家进入问答时范围明确；未关联项目或专家已删除时不能扩大成全局问答。
- [ ] 今天的行动排除已完成、暂停、等待状态及暂停／归档项目，不凭空生成日期。
- [ ] 手动完成／解决后可恢复未被再次修改的记录；并发修改和重复撤销明确拒绝。
- [ ] 删除细项有明确确认；旧版本的确认窗口不能删除期间已修改的记录。
- [ ] 独立事项的分析轮次互不阻塞；同名但来源不同的新事项不会被旧建议误挡。
- [ ] 多项目同时分析时，用户方向与拒绝理由能进入对应范围；未绑定目录的专家证据仍可使用。
- [ ] 待审阅／待推进的事项保持安静；实际推进后才继续，迟到结果不能覆盖期间的决定。
- [ ] 新旧格式报告均能阅读；结构化条目的来源可定位，删除或跨设备不可用的资料明确提示。
- [ ] 报告中提出的新行动先进入可编辑确认流程，连续点击不重复落地。

## 文件、资料与模型

- [ ] 仅绑定隔离环境中的合成目录。目录变化由测试准备过程产生，应用本身不增删源文件。
- [ ] 专家资料保存副本，支持格式进入提取/读取流程，不支持格式明确标记。
- [ ] 清理缓存后正式附件、保留报告与未处理建议完整。
- [ ] 三类模型协议真实发送合成文本/文件字节，缺失来源、截断、拒绝、超限和异常响应不伪装成功。
- [ ] 切换页面不中断后台任务；失败状态能被看见并可重试。
- [ ] 所有正式业务变动来自明确的用户操作或确认。

## 同步、备份与故障

- [ ] 空目录初始化、有数据目录方向选择、手动同步与可调周期正常。
- [ ] 两个独立数据库及独立模拟云盘目录验证离线编辑、标识冲突、乱序到达、损坏分块和删除传播。
- [ ] 冲突保存或业务写入失败时整批回滚；恢复/基线不一致时停止同步。
- [ ] 无变化同步不新增完整副本；保留策略不清理其他设备或未知文件。
- [ ] 专家附件及证据关系同步后指向正确资料，已删除来源不进入后续分析。
- [ ] `native-persistence-cdp.mjs` 验证实际 IPC、备份和同步，强制结束隔离实例后用 `--reopened` 核对持久化。
- [ ] `workflow-continuity-native.mjs` 验证恢复凭据、专家问答范围及结构化报告，重启后用 `--reopened` 核对保存状态。
- [ ] `native-load-cdp.mjs` 验证一万条任务的并发写入与同步。
- [ ] `native-large-list-cdp.mjs` 验证同批数据下的分页、最后一条记录和表单响应。
- [ ] 实际双机云盘、长时间离线、磁盘不足、硬件断电及长期运行单独记录结果。模拟通过不能替代尚未执行的实机测试。

## 结论记录

记录构建版本、摘要、通过项、失败项、未执行项及证据位置。存在未完成的生产门时保留候选状态，不以“构建成功”代替生产验收。
