# MSL Desktop C1 UI 重建设计规范

## 1. 目标

将现有通用 SaaS 风格界面升级为“编辑式 AI 秘书工作台”。视觉采用 C1 雾蓝银灰方案，突出医学工作的专业、克制、清晰与陪伴感。所有现有业务能力继续可用，界面重建不得破坏数据写入、AI 建议确认、目录索引、模型设置、存储治理和中英文切换。

## 2. 已确认的设计方向

- 风格：编辑式秘书桌。
- 配色：雾蓝、银灰、瓷白、深青灰。
- 首页：每日简报为首屏视觉中心，工作状态、今日推进、待确认建议、目录变化、AI 翻译和秘书状态在一个桌面窗口内完成浏览。
- 内页：固定使用“列表 / 主内容 / 辅助操作”三级结构；较窄窗口隐藏辅助栏，将辅助操作放入抽屉或弹窗。
- AI 操作：生成结果先进入可编辑草稿，明确显示来源和写入范围，用户确认后写入正式实体。

## 3. 视觉系统

### 3.1 色彩

- 页面背景：`#f1f4f5`
- 内容背景：`#f7f9f9`
- 卡片：`#fbfcfc`
- 侧栏：`#e3e9eb`
- 主文字：`#263640`
- 次要文字：`#718088`
- 弱文字：`#91a0a6`
- 边框：`#dbe3e6`
- 主操作：`#687f8b`
- 主操作悬停：`#596f7a`
- 主操作浅底：`#e7eef1`
- 成功：`#6f8d82`
- 提醒：`#9b7f5e`
- 危险：`#9f6f6f`

界面不得使用大面积纯黑侧栏、荧光蓝主按钮、高饱和渐变或厚重阴影。

### 3.2 字体与间距

- 正文：`Segoe UI`, `Microsoft YaHei`, system-ui。
- 首页简报和主要页面标题可使用 Georgia 与中文衬线字体回退。
- 正文基准字号 13px；辅助文字 11px；页面标题 22–24px。
- 基础间距 4px；常用间距 8、12、16、20、24px。
- 卡片圆角 14px；输入框和按钮圆角 9–10px；窗口级容器圆角不在 Tauri 正式窗口内重复绘制。
- 阴影保持低对比度，仅用于弹窗、浮层和少量重点容器。

## 4. 应用外壳

- 左侧栏常规宽度 194px，窗口宽度低于 1100px 时收为 68px 图标栏。
- 导航按“工作台”“智能秘书”“系统”分组。
- 每个导航项使用统一线性图标、标签和可选数量徽标。
- 顶栏高度 68px。左侧显示当前页面和日期，中间保留快速记录，右侧提供搜索、语言切换和用户标识。
- 内容区域承担滚动；首页在常见桌面高度下保持无页面滚动。
- 侧栏底部显示 AI 秘书状态和下次分析时间；数据暂不可用时显示中性状态。

## 5. 首页

首页从上到下分为两层。

### 5.1 每日简报

- 使用跨栏浅雾蓝容器，显示生成时间、简报标题、摘要和主要操作。
- 优先呈现 3 条今日推进事项；没有可用简报时呈现清晰空状态与生成按钮。
- 保留范围选择、重新生成、来源展开和 AI/本地摘要标识。
- 详细简报和来源通过弹窗或展开层查看，避免撑高首页。

### 5.2 今日工作区

- 指标使用细条展示：进行中工作、今日待办、等待回复、待确认建议、本周/今日日程。
- 左侧主列展示时间线和继续推进事项。
- 中列展示待确认 AI 建议、等待事项、收件箱和目录变化。
- 右列常驻 AI 翻译和秘书运行状态。
- 空状态应保留原布局尺寸，防止模块跳动。

## 6. 内页通用结构

- 页面标题区：标题、简短说明、主要操作。
- 列表页优先使用 240–280px 选择栏、可伸缩主内容区、300–340px 辅助区。
- 任务、等待事项、日历、收件箱在现有业务结构上统一卡片、筛选、表单、状态徽标和空状态。
- 设置页使用左侧分类目录与右侧设置内容；长页面允许内容区域独立滚动。
- 模态框采用柔和遮罩、明确标题、固定操作区和可见关闭按钮。
- 所有按钮必须具有悬停、键盘聚焦、加载和禁用状态。

## 7. 工作项目与 AI 确认

- 工作项目左栏显示名称、阶段、更新时间和简洁进度信息。
- 主内容显示摘要、继续推进、关联任务、等待事项、日程、文件和最近活动。
- AI 工作草稿放在右侧辅助栏；字段可直接编辑，显示信息来源和将要创建的实体。
- 窄窗口通过抽屉或现有 AI 审阅页完成确认。
- “确认并创建”执行现有提案确认链路；界面重建设计不绕过数据库保护规则。

## 8. 国际化与文案

- 中文为默认语言，英文继续覆盖所有新增固定文案。
- 中文文案简短、直接、专业。按钮尽量使用 2–6 个汉字。
- 页面避免重复显示产品名和页面名。
- 时间、日期与状态继续根据当前语言格式化。

## 9. 响应式与可访问性

- 目标桌面尺寸：1024×640、1280×720、1440×900。
- 1024px 宽度时收起侧栏标签，首页隐藏秘书状态卡中的次要日志，内页辅助栏转为按需入口。
- 所有交互控件保留 `data-testid`，以兼容现有 CDP 冒烟测试。
- 键盘焦点使用 2px 雾蓝描边；状态信息不得只依赖颜色表达。
- 正文与背景的对比度以 WCAG AA 为目标。

## 10. 实施边界

- 保留 Svelte 5、SvelteKit、Tauri 2 和现有 API 接口。
- 不新增图标依赖，使用本地 SVG 图标组件。
- 不修改正式数据库、真实 API Key 或正式工作目录。
- 不覆盖当前工作树中的已有成果，不执行 reset、checkout、clean、stash、rebase、commit。
- 本轮聚焦 UI 架构、视觉系统和现有功能的界面承载；数据库和 AI 后端行为保持当前实现。

## 11. 验收

- `pnpm check` 通过。
- `pnpm build` 通过。
- UI CDP 冒烟通过，既有关键 `data-testid` 可定位。
- 隔离运行截图覆盖首页、工作项目、AI 审阅、设置页。
- 首页在 1024×640 和 1440×900 下无外层页面滚动。
- 中英文切换后导航、主要操作和新增文案正确显示。
- 新建、编辑、确认、搜索、快速记录等现有关键操作仍可进入原有处理链路。
